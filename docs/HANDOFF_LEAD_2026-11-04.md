Сделано: инвентаризация, swap, Docker/Nginx/age, API на loopback, SSH только по ключу, ufw (22/443), DNS, Let's Encrypt, HTTPS со списком IP, ответ `ready` с телефона пользователя.

4. `backup-now.sh` → `verify` с офлайн-ключом age → `restore-test.sh`; timer только после этого.
5. Перенести `/root/backup-tls.key` с VPS офлайн (`move-backup-key.ps1`).
6. WireGuard (`wireguard.sh`) и IP второго телефона в allowlist.
7. Передать `server-endpoint.json` (`{origin, pins}`) для телефонов; проверить цепочку Let's Encrypt (`YR1`) именно на Android 8.
8. Проверить отзыв сессий и выключение операторских путей после теста.

## Как работать ведущему

- Исполнительские сессии не видны через `list_sessions`; команды им — комментариями в их PR и текстом для пользователя.
- Облачная сессия не имеет SSH к VPS и не может удалять ветки; эмулятора локально нет — Android проверяется в CI (`android-emulator.yml`).
- Перед слиянием: зелёный CI на голове PR; одна повторная попытка допускается только для известного редкого крэша.
- Плановые проверки исполнителей: при трёх подряд без изменений остановиться и сообщить пользователю один раз.
- Ответы пользователю — по-русски, в конце каждого сообщения строка «Готовность: закрытый тест ~N%, полное ТЗ ~M%».
