## 1. Авторизация и доверенные прокси

Применить/адаптировать PR #2 trusted-proxy и выполнить регрессию. Пустая Auth:TrustedProxies не доверяет
X-Forwarded-For; доверять только явному адресу Nginx. Подмена заголовков и два экземпляра API не обходят
5 SMS / 10 минут. Проверить код, PIN, device proof, refresh/replay, один активный device и отзыв.
Использовать настоящий PostgreSQL18 и HTTP. Android payload совместим с имеющимся Java fixture.
SMS.ru сверить с официальной документацией: ограниченный ответ, таймауты/ошибки, без скрытых повторов,
лимиты расходов. Fake по умолчанию; платные SMS без отдельного решения не отправлять.

## 2. Закрытый HTTPS

Воспроизводимые Nginx/Compose/env с placeholders, без секретов в git. TLS1.2+, корректные CA/hostname,
allowlist тестировщиков с default deny. API и PostgreSQL недоступны извне. SSH по ключу, снаружи 443/22.
Production guard не снимать ради стенда; Development только за закрытым входом. Операторские dev SMS,
provisioning/OpenAPI ограничить отдельно. Операторский секрет в APK не добавлять.
Публичный ServerEndpoint JSON: {origin,pins}, точный HTTPS origin и текущий/резервный SPKI pins,
без bearer/admin/password. Клиентские trust/hostname/pinning не отключать.
Если домен/VPS/доступы отсутствуют, сдать проверенные конфиги/runbook и точный блокер; не заявлять
развёртывание выполненным, не менять DNS и не создавать платные ресурсы.

## 3. Доставка и восстановление

Запустить существующие JVM smoke-клиенты с настоящим libsignal против HTTP API и PostgreSQL:
два аккаунта, prekeys, текст туда/обратно, офлайн-получатель, потеря ответа/идемпотентный повтор,
ACK, перезапуск API, refresh и перенос устройства с отзывом старого. Криптографию заглушкой не заменять.
Согласовать публичный JSON стенда с Android-исполнителем. Софтовые клиенты не называть двумя телефонами.

Зашифрованная резервная копия БД и фактическое восстановление в отдельную пустую БД. Учесть JWT/pepper/
DataProtection и ключ резервной копии отдельно; не коммитить/логировать их. Рабочие volume/БД не трогать,
не использовать down -v для очистки. Добавить шаги ручной проверки двух физических ARM64 телефонов.
