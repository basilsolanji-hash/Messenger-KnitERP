# Архитектурные решения

## Отдельный репозиторий

Messenger-KnitERP — самостоятельный проект мессенджера. Фирменный знак knitERP сохранен в `assets/knitERP_logo_selected.png`. Этот проект не меняет код ERP и не требует ее базы данных.

## Сначала транспорт

Первая поставка содержит серверный транспорт, постоянную очередь и проверяемые ограничения доступа. Клиентское шифрование должно подключаться отдельным модулем на настоящем libsignal. Серверное AES-шифрование и единый общий ключ всех пользователей не являются заменой E2EE.

## Лицензирование

Код предоставляется под AGPL-3.0-only; полный текст находится в `LICENSE`. Для дальнейшей интеграции libsignal предусмотрено предоставление соответствующих исходников. До включения зависимости нужно добавить ее уведомления и проверить лицензии конкретных версий. Графический логотип не предоставляется как свободная торговая марка по лицензии кода.

## Локальная среда

Рабочее окружение отсутствует намеренно. Compose публикует API на loopback, а сервер требует Development. Учетные записи создаются тестовым адаптером без SMS-платежей. Развертывание на Beget допускается после завершения авторизации, криптографических тестов и эксплуатационной подготовки.

## Решения пользователя 25 октября 2026 года

Записаны по ответам пользователя ведущему исполнителю.

- Цепочка PR #1–#8 слита в `main` перемоткой на проверенный `13b9988`, без force-push.
- Закрытый тест: VPS и домен есть; доступы передаются вне чата и git. SMS — Fake-провайдер, код выдает оператор вне APK; платные SMS.ru не отправляются. Доступ к стенду — по списку IP с запретом по умолчанию; мобильный интернет со сменой IP не поддерживается без отдельного решения.
- Телефоны: два физических, один на Android 8, второй на актуальном Android.
- Название на закрытом тесте — «Ось коммуникации» с прежним логотипом.
- Android instrumentation запускается в GitHub Actions на эмуляторах API 26 и актуального Android до проверки на телефонах.
- Звонки — после 1.0: личные в 2.0, групповые в 2.1 (`PRODUCT_SPEC.md`, раздел 9).
- Срок хранения истории — настройка пользователя; выключенная означает бессрочное хранение. Это относится к истории на телефоне и к зашифрованным файлам на сервере, с квотой объема; текст переписки сервер не архивирует (`PRODUCT_SPEC.md`, раздел 10).
- Доступ к стенду с мобильного интернета: пользователь выбрал «все возможности» — WireGuard на том же VPS (split-tunnel только до стенда). Снаружи дополнительно открыт UDP 51820. Риск: блокировка WireGuard операторами РФ; AmneziaWG — только отдельным решением. Исполнение — PR #9.
