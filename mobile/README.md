# Android и libsignal — прототип

Текущий Android APK запускает **два локальных тестовых профиля на одном телефоне**. Сообщения действительно обрабатывает libsignal, а история хранится через Room/SQLCipher. Это ещё не чат с другим телефоном: приложение не запрашивает разрешение INTERNET и не выполняет регистрацию.

Языки интерфейса: русский (fallback), белорусский, казахский, узбекский (латиница). Выбор в «Настройки → Язык приложения» сохраняет AppCompat; Android 13+ также поддерживает системную настройку языка приложения. Содержимое сообщений при смене языка не переводится.

## Сборка

Нужны JDK 21 и Android SDK Platform 36 / Build Tools 36.0.0. Из этой папки:

```bash
./gradlew :core:test :app:assembleDebug :app:assembleDebugAndroidTest
```

APK: `app/build/outputs/apk/debug/app-debug.apk`. Это сборка с тестовой подписью для проверки, не релиз для Google Play. Не добавляйте debug-keystore, секреты или `local.properties` в git.

Проверка на подключённом устройстве/эмуляторе:

```bash
./gradlew :app:connectedDebugAndroidTest
```

Инструментальные тесты проверяют транзакционный откат Room, шифрование файла, повторную доставку после переоткрытия базы и разрешение четырёх локалей. Их наличие в репозитории не означает, что они уже выполнены; результаты находятся в `../docs/VALIDATION.md`.

## Проверка через сервер

Из корня репозитория, с отдельной тестовой PostgreSQL на loopback:

```bash
dotnet build server/Messenger.Api -c Release
export TEST_DATABASE='Host=127.0.0.1;Port=5432;Database=messenger_crypto_test;Username=messenger;Password=YOUR_TEST_PASSWORD'
python3 scripts/check-e2ee.py
```

Скрипт запускает временный API на случайном loopback-порту с миграцией тестовой базы, случайными секретами и двумя синтетическими клиентами. Проверяет выдачу настоящих ECC/PQ prekeys, повтор claim/send, офлайн inbox, расшифровку, потерянный ACK и ответ. Секреты не записываются в исходники или APK. Без `TEST_DATABASE` этот сценарий завершается ошибкой; обычный `:core:test` его не запускает.

## Криптографические границы

- `core` использует `org.signal:libsignal-client:0.105.4` из официального Maven-репозитория Signal; Android дополнительно подключает `libsignal-android` той же версии. Использование вне Signal не поддерживается разработчиком библиотеки, API может изменяться.
- Библиотека отвечает за криптографические операции. Код приложения связывает идентификаторы отправителя, адресата, устройства и сообщения внутри зашифрованного тела с внешним конвертом.
- Ratchet, использованные одноразовые prekeys, plaintext-история и outbox сохраняются одной транзакцией. Повтор отправки возвращает тот же шифротекст, а повтор получения — сохранённое сообщение.
- TOFU не защищает от подмены самого первого контакта. Модуль предоставляет 60 цифр и сравнение QR payload; камера/сканер QR ещё не подключены.
- Смена identity или устройства останавливает переписку. Поток подтверждения нового устройства и подписанные device challenges ещё предстоят.
- Room использует SQLCipher и случайную 256-битную passphrase, защищённую AES-GCM ключом Android Keystore. Приватные ключи Signal хранятся внутри зашифрованной базы, а не как экспортируемые ключи Keystore. Потеря Keystore-ключа не включает обход шифрования или автоматическое удаление данных.
- Системное резервное копирование/перенос отключены. Зашифрованный Google Drive backup будет отдельным модулем.
- На этом этапе ещё нет ротации prekeys, пополнения пулов, истории с пагинацией, подкачки очереди, сетевого адаптера Android, SMS/PIN, push и независимого аудита безопасности.
